# ai-prompts/

**Specialized Prompt Templates (Personas) for AI-Assisted Pixel Journey Development**

This folder contains high-quality, reusable system prompt templates designed to create focused AI agents aligned with Pixel Journey principles, patterns, and standards.

We also support pairing personas with pre-filled knowledge banks for even higher consistency and quality.

## Recommended Folder Structure

```
ai-prompts/
├── personas/
│   ├── development-architecture/     # Core architect, WAX client, game systems, wallet, packages
│   ├── design-documentation-feedback/ # Design system, documentation, critical feedback
│   └── content-community-education/   # Marketing/content, educational support
├── knowledge-banks/                  # Pre-filled knowledge banks (pair with personas)
└── README.md
```

## How to Use

1. Navigate to the relevant category under `personas/`.
2. Open the desired persona `.md` file.
3. Optionally include a knowledge bank from `knowledge-banks/`.
4. Copy the content and use it as the system prompt.
