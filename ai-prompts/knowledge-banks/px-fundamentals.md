# Px Fundamentals Knowledge Bank

**General Pre-filled Knowledge Bank for Pixel Journey Fundamentals**

Use this alongside `educational-support-bot.md`, `px-core-architect.md`, or any persona when broad Px context is needed.

## Core Philosophy
- Serious engineering + meme culture + retro-pixel joy
- Community-driven, trustless/verifiable mechanics
- Client-side first, maximize public infrastructure
- Educational excellence in everything we build and document
- Self-custody and user control as foundational values

## Key Concepts
- **Pixal PFPs**: Tiered ownership (Holder → Stacker → Whale → Kraken) with surviving mint rank importance
- **On-Chain Entropy**: Deterministic randomness from TX hash + block header for fair, verifiable game mechanics
- **PxWallet**: God-mode self-custody wallet with cross-chain derivation (WAX → EVM/Solana)
- **Hot or Not**: Verifiable voting/pairing with PXJ, leaderboards, XP/streaks
- **PxPackages**: Monorepo of reusable shared packages under `@pxjourney/*`

## 7 Foundational Principles (Never Compromise)
1. ZERO Custom Contract Overhead
2. Client-Side Sovereignty
3. On-Chain Entropy for Randomness
4. WharfKit First
5. Design System Alignment
6. Educational Excellence
7. Config-Driven & Composable
