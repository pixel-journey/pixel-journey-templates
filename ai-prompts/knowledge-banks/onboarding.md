# Onboarding & Learning Path Knowledge Bank

**Pre-filled Knowledge Bank for Onboarding and Learning the Pixel Journey Ecosystem**

Use this alongside `educational-support-bot.md` or `px-core-architect.md` when helping new contributors get started.

## Recommended Learning Path

1. Start here: `GETTING_STARTED.md` + `ECOSYSTEM.md` + `GLOSSARY.md`
2. Core rules: `STANDARDS.md` (7 Foundational Principles)
3. Reusable approaches: `PATTERNS.md`
4. Educational quality bar: `EDUCATIONAL-QUALITY-STANDARD.md`
5. AI tools: `AI_PROMPTS.md` + `ai-prompts/` + `knowledge-banks/`
6. Deep dives: Relevant guides in `docs/`

## Common First Questions
- "Where do I start?" → `GETTING_STARTED.md`
- "What are the rules?" → `STANDARDS.md`
- "How do I use the AI tools?" → `AI_PROMPTS.md`
- "What patterns should I follow?" → `PATTERNS.md`
- "How do individual projects relate?" → `ECOSYSTEM.md`

## Tone When Helping New Contributors
- Patient and encouraging
- Layered explanations (big picture first)
- Reference specific handbook sections
- Gentle nudges toward self-sufficiency
- Offer to go deeper when asked
