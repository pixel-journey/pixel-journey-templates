# GLOSSARY.md

**Key Terms in the Pixel Journey Ecosystem**

This glossary provides quick definitions for important terms used across our handbook, patterns, and projects.

## Core Concepts

- **Pixal**: Pixel Journey PFP collection with tiered ownership (Holder, Stacker, Whale, Kraken, WaxRock).
- **Surviving Mint Rank**: The original mint position among non-burned assets — critical for early supporter recognition and certain leaderboards.
- **On-Chain Entropy**: Deterministic randomness derived from a transaction hash + recent block header. Used for fair, verifiable game mechanics without oracles.
- **Verifiable Pairing**: Match generation in Hot or Not that can be independently verified via on-chain data (TX memos + entropy).

## Technical Terms

- **WharfKit**: The modern Session/Account/Contract Kit used for all WAX interactions (replaces legacy UAL/eosjs).
- **AtomicAssets**: Public NFT standard and API on WAX (used for Pixals and collections).
- **Hyperion**: Public history/indexing API for WAX (used for deltas, actions, and data pipelines).
- **Alcor**: Concentrated liquidity AMM on WAX (alcorammswap).

## Project Terms

- **PxWallet**: God-mode self-custody wallet with encrypted vault and cross-chain key derivation.
- **Hot or Not**: Verifiable voting/pairing arena with PXJ mechanics, leaderboards, and progression systems.
- **PxPackages**: Monorepo initiative for reusable shared packages under `@pxjourney/*`.
- **YEET**: Community meme coin with airdrops, staking, and PFP integration (no team taxes).

## Documentation & AI Terms

- **Knowledge Bank**: Pre-filled structured context (Markdown) that can be paired with an AI persona for higher consistency and quality.
- **Persona**: Specialized AI prompt template focused on a particular domain (e.g., `game-systems-designer.md`).

This glossary will continue to grow as new patterns and projects emerge.
