# Contributing to Pixel Journey Projects

Thank you for considering contributing!

## How to Contribute
1. Fork the repo
2. Create a feature branch
3. Make changes following our standards
4. Submit a PR with clear description

## Development Setup
See project-specific README.

## Code Review
All changes require review (Google-style rigorous process).

Follow our [engineering standards](https://github.com/pixel-journey/pixel-journey-templates).
