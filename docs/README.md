# docs/

**Educational Guides for the Pixel Journey Ecosystem**

This folder contains deeper, focused guides on important technical and architectural topics.

## Current Guides

- `GETTING_STARTED.md` — Practical onboarding guide for new humans and AI agents (recommended starting point).
- `WAX_CLIENT_SIDE_PATTERNS.md` — How we build reliable experiences using only public WAX infrastructure.
- `ONCHAIN_ENTROPY_GUIDE.md` — The verifiable randomness pattern that powers fair, trustless game mechanics.

## Purpose

These guides exist to:
- Accelerate onboarding for new team members and contributors
- Provide the "why" and deeper context behind the patterns in `PATTERNS.md`
- Serve as living reference material that improves over time

New guides are added when a topic becomes important enough to deserve dedicated educational treatment.

All guides aim for the same high standard: clear, layered, scannable, and directly useful for building consistent Px experiences.
