# Pixel Journey Templates & Standards

This repository contains templates, workflows, and standards for all Pixel-Journey projects. Aligned with top engineering practices (Google-inspired).

## Contents
- `.github/` - Issue/PR templates, workflows
- `LICENSE` - MIT License
- `CONTRIBUTING.md` - How to contribute
- `CODE_OF_CONDUCT.md` - Community standards

Use this repo as a **template** for new projects.

## Quick Start for New Repos
1. Use `pixel-journey-templates` as template
2. Customize project-specific files
3. Enable branch protection on `main`
4. Set up GitHub Actions

See full standards in our [GitBook docs](https://pixeljourney.xyz).
